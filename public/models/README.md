# Bundled detector

`sample-symbols.onnx` is an original 436-byte ONNX model generated by `scripts/make-sample.mjs`. It computes L1 distances between RGB pixels and five sample symbol colors. It has no external tensors, network calls or training data. It is deliberately a tiny demonstration detector, **not a trained YOLO or general plumbing-symbol model**. Original sample drawings and model are released under CC0-1.0.

Input: float32 `pixels`, shape `[N, 3]`, RGB normalized to 0–1. Output: float32 `distances`, shape `[N, 5]`. Class order: Fixture, Valve, Floor drain, Hydrant, Cleanout. The app thresholds distances, extracts connected components and merges overlapping tiles. Pipe geometry uses a separate raster heuristic.

For a plumbing-trained YOLO11n-class detector, export to ONNX using input `[1,3,640,640]`, float32, `nms=False`, `dynamic=False`, and raw output `[1,4+C,N]`. Place the ONNX in this directory, rebuild, choose Custom YOLO in Detection settings and enter `/models/plumbing.onnx` with the correct ordered class labels. Only detection exports are supported, not segmentation, rotated-box or end-to-end NMS exports. Check the model's own license and training coverage. No licensed commercial Beam/iBeam code, models or assets are included.
